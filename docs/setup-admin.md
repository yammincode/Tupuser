# 總部後台與入場機：設定步驟（老闆操作說明）

大約 15 分鐘。前提：已經照 `docs/setup-counter.md` 在電腦上跑起系統（`npm run dev`）。

---

## 步驟 1：執行資料庫更新（1 分鐘）

到 Supabase 的 **SQL Editor** → **+ New query**，貼上以下檔案內容後按 **Run**：

- `supabase/migrations/20260929000009_kiosk_admin.sql`（入場機讀取分館設定用）
- `supabase/migrations/20260929000010_reports.sql`（營收報表用）
- `supabase/migrations/20260930000012_reports_more.sql`（報表擴充：銷售、入場、月／年比較、會員、未使用餘額）

一個檔案一個 query，依順序執行。

如果 0006～0008 還沒執行，請先依序執行。

---

## 步驟 2：部署「帳號管理」功能（5 分鐘）

總部後台要能**建立員工帳號、入場機帳號、重設密碼**，這需要放在 Supabase 伺服器上的小程式（Edge Function）。只要設定一次。

1. 在 GitHub 打開 `supabase/functions/admin-users/index.ts`，按右上角**複製圖示**，複製全部內容。
2. 到 Supabase 後台，左邊選單點 **Edge Functions**。
3. 按 **Deploy a new function**（部署新功能），選 **Via Editor**（在網頁編輯器裡寫）。
4. 把**名稱**改成：`admin-users`（一定要一模一樣）。
5. 把編輯器裡原本的範例程式**全部刪掉**，貼上剛剛複製的內容。
6. 按 **Deploy function**。看到綠色的成功訊息就完成了。

> 這個功能會自動使用 Supabase 的最高權限金鑰，金鑰只存在伺服器上，不會外流到畫面裡。
> 程式裡會先檢查：只有**在職的總部或店長**能使用；店長只能建立自己分館的櫃檯和入場機。

---

## 步驟 3：打開總部後台

瀏覽器網址輸入 `http://localhost:5173/admin`，用您的總部帳號登入。

上方有六個分頁：

| 分頁 | 可以做什麼 |
|---|---|
| **品項管理** | 新增品項、點品項修改（名稱、分類、價格、內容、數量、平日／假日／時段、適用分館、上架期間）、下架／重新上架 |
| **員工與權限** | 新增員工（建立登入帳號）、修改角色與分館、停用離職員工、重設密碼 |
| **分館與入場機** | 各店固定零用金、入場機音量（可試聽）、品牌名稱、頂欄顏色、地址電話、營業狀態；新增入場機帳號；國定假日 |
| **訂單** | 查任何一天、任何分館的訂單，或直接搜尋訂單編號；**作廢其他日期的訂單**、退費、修改備註／業務代表／發票資料（已關帳的日子也能改，系統會留下修改紀錄） |
| **報表** | 上方切換六種報表（店長只看得到自己分館），每種都可以按「匯出 Excel」：<br>・**總覽**：淨營收、訂單、入場、新會員、每日營收圖、各分館、品項排行、關帳差額<br>・**銷售**：依分類（點分類可篩選品項）、品項、付款方式、折扣原因、業務代表業績、客單價<br>・**入場**：依票種的人次與人數、依方案、尖峰時段熱度圖、平日假日、入場機／櫃檯、被擋下原因<br>・**月／年比較**：最近 13 個月（比上月、比去年同月）；每年（今年到今天 vs 去年同期、各分館、各分類）<br>・**會員**：即將到期名單、很久沒來名單（可只看同意行銷的）、新會員回訪率<br>・**未使用餘額**：已收款但會員還沒用掉的票券價值（依票種、分館、品項） |
| **同意書** | 查看各版本與簽署人數；**發布新版本**（到了生效日，所有會員要重新簽才能入場）；還沒人簽過的版本可以修改 |

品項管理頁右上角另有「**分類管理**」（只有總部看得到）：可改分類名稱、顏色、順序，或新增分類。

建議先做：
1. **分館與入場機** → 填好各店**固定零用金**，按「儲存」。
2. 同一頁 → 加上今年剩下的**國定假日**。
3. **員工與權限** → 新增各店店長與櫃檯人員。

---

## 步驟 4：設定入場機平板

1. 到 **分館與入場機** → **＋ 新增入場機**：選分館、取名（例：萬華入場機 1）、自訂一組 Email（例：`kiosk-wh1@origin.tw`，不需要真的能收信）和密碼。
2. 在入場機平板的瀏覽器（建議 Chrome）打開：`http://電腦的網址:5173/kiosk`
   （網址看 `npm run dev` 畫面上 `Network:` 那一行，例如 `http://192.168.1.23:5173/kiosk`）
3. 用剛剛建立的入場機 Email 和密碼登入。之後會一直保持登入。
4. 畫面出現「**點一下開始使用入場機**」，點一下（這一下是讓平板允許播放提示音，並切換成全螢幕）。
5. 把 USB 掃碼器插上平板，就可以掃會員的 QR code 了。

> 平板遺失或要換新的：到 **分館與入場機** 按該台的「停用」，舊平板就立刻不能用。
