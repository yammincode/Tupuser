# 版本紀錄

每次「更新正式版」版本號 +0.1（v1.3 → v1.4 …），數字寫在 `web/src/version.js`。
上線後打開任一系統，看到的版本號和這裡最新一版相同，就代表新版已經上去了。

**畫面上看版本號的位置**
- 櫃檯、總部後台：右上角名字 ▾ 選單最下方「系統版本 v1.x」；登入頁的登入按鈕下方也有
- 入場機：畫面右下角淡淡的小字
- 會員 App：登入頁最下方、入場碼頁最下方
