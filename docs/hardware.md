# 硬體採購清單

> 2026-09-29 整理。價格是台灣網購（PChome、momo、蝦皮）的大約行情，僅供估算。
> **建議先買「試跑分館一套」**，在試跑分館測過沒問題，再買其他分館的。

## 一、每間分館需要什麼

### 櫃檯（1 套）

| 項目 | 規格重點 | 參考價格 |
|---|---|---|
| 平板 | 10～11 吋、**橫放**、有前鏡頭（新會員拍大頭照）。建議 Android（例：Samsung Galaxy Tab A9+ 或同級），或 iPad（第 10 代以上）。記憶體 4GB 以上 | Android 約 6,000～8,000；iPad 約 11,000～13,000 |
| 平板支架 | 可旋轉（轉向客人簽同意書）、可鎖在桌上 | 800～2,000 |
| 掃碼器（手持式附座） | **二維條碼（QR）＋能掃手機螢幕**；**USB 有線、「鍵盤模式」**（插上就能用，不用裝程式）；掃完自動按 Enter（大多數出廠就是） | 1,000～2,500 |
| USB-C 轉接器（集線器） | **有 PD 充電孔**：平板一邊接掃碼器、一邊充電 | 600～1,200 |
| 觸控筆（選購） | 簽名比手指好寫，一般圓頭電容筆即可 | 100～300 |

### 入場機（1 套，入口處）

| 項目 | 規格重點 | 參考價格 |
|---|---|---|
| 平板 | 10～11 吋、**建議 Android**（可以鎖成只開入場機畫面）。規格同櫃檯即可 | 6,000～8,000 |
| 防盜平板支架 | 橫放、**可上鎖**、固定在牆面或立架上；看得到螢幕、聽得到喇叭 | 1,500～4,000（落地立架約 3,000～6,000） |
| 掃碼器（感應式／桌上型） | **免手持**：會員把手機靠過去就自動掃。同樣要 **QR、能掃手機螢幕、USB 鍵盤模式、自動 Enter** | 1,500～4,000 |
| USB-C 轉接器（集線器） | 同櫃檯，**一定要有 PD 充電孔**（入場機整天開著） | 600～1,200 |
| 鎖定畫面軟體 | Android 用「Fully Kiosk Browser」（付費版一台約 300 元，一次買斷）：開機自動開入場機網頁、不能跳出、不會休眠 | 約 300 |

### 網路

- 櫃檯和入場機都要連 **穩定的 Wi-Fi**（系統在網路上執行，斷網就不能結帳和入場）。
- 建議：分館路由器放在櫃檯附近；有餘裕的話加一台 **4G 備援路由器**（插 SIM 卡，斷網時自動接手，約 2,000～4,000 元＋每月網路費）。

### 先不要買

| 項目 | 原因 |
|---|---|
| 發票／收據印表機 | 要看選哪一家**電子發票加值中心**，不同家支援的印表機不同。選定後再買（常見的是 Epson TM 系列熱感印表機，約 8,000～12,000） |
| 錢櫃 | 一般接在收據印表機上一起開，等印表機決定後一起買。在那之前繼續用現有的錢櫃 |
| 電腦 | 總部後台用現有電腦或筆電的瀏覽器就可以 |

## 三、買的時候要注意（很重要）

1. **掃碼器一定要寫「支援手機螢幕」或「螢幕條碼」**，而且**一維、二維條碼都能掃**（櫃檯要掃會員 QR，也要掃客人手機上的發票載具條碼，那是一維條碼 Code39；影像式掃碼器大多兩種都支援）。便宜的「雷射」掃碼器只能掃紙上的一維條碼，**掃不了手機上的 QR code**。要找「**2D／二維／影像式（CMOS）**」的。
2. **掃碼器要「USB 有線」＋「鍵盤模式（HID）」**。藍牙的會斷線，入場機不建議。
3. **平板要能同時接掃碼器和充電**：有些平板接了 USB 裝置就不能充電，所以要買**有 PD 充電孔的 USB-C 轉接器**。買之前可以先問賣家「平板接轉接器後能不能邊充電邊用 USB 裝置」。
4. 建議**先各買一台**，拿到後用系統的 `/kiosk` 和 `/counter` 實際掃會員 QR 測試，沒問題再買其他分館的。
5. 入場機選 Android 的原因：iPad 的瀏覽器不能完全鎖成單一畫面、全螢幕也有限制（可以用「引導使用模式」勉強代替，但每次重開要重新設定）。櫃檯用 iPad 沒有問題。
